# Gerador de Rifas Escolares

Aplicação web para criar rifas escolares numeradas e preparar os bilhetes para impressão.

## Recursos

- Definição do intervalo de números e da quantidade de rifas por folha, até o limite de 8.
- Campos para o nome da escola, título da rifa, valor, aviso e prêmios.
- Opção para inserir a logo da escola.
- Seleção da fonte e da cor de destaque dos bilhetes.
- Canhoto destacável com espaço para nome e telefone.
- Impressão ou salvamento dos bilhetes em PDF pelo navegador.

## Como usar

1. Abra o site do gerador.
2. Preencha os dados da rifa e escolha a fonte, a cor e, se desejar, a logo.
3. Confira a prévia.
4. Clique em **Gerar PDF** e escolha **Salvar como PDF** ou uma impressora na janela de impressão.
